# 동료 사용 확인

이 문서는 실행 안내다. 아직 동료의 참여나 실제 사용 결과를 기록한 문서가 아니다.

## 준비

- 사용자 본인이 동료 2~3명에게 참여를 요청한다. 에이전트는 메시지를 보내지 않는다.
- 한 사람당 첫 확인 20분, 3~7일 후 다시 확인 10분을 잡는다.
- 미리보기에서 진행할 때는 가상 오피스 예시를 사용한다. 실제 딜 사용은 운영 배포 승인 후 각자 본인 환경에서 수행하며 수치·회사명·파일은 받지 않는다.
- 관찰자는 먼저 사용법을 설명하지 않는다. 도움이 필요했던 위치를 기록한다.

## 첫 사용 과업

1. 모바일에서 오피스 예시를 열고 매입가와 임대료를 바꾼다.
2. 본인이 바꾼 값과 남은 예시값을 찾아 설명한다.
3. 결과를 확인하고 PC 이어보기 링크를 복사한다.
4. PC에서 같은 조건을 확인한다. 기존 미저장 작업이 있다면 먼저 저장하고 돌아온다.
5. 자기 모델로 열어 조건 하나를 바꾸고 엑셀을 내려받는다.
6. 현재 조건을 저장한다.

## 3~7일 뒤 과업

저장한 검토를 열고 매입가 또는 대출 조건을 바꿔 새 버전으로 저장한다. 이전 조건과 결과의 차이를 확인한다. 실제 업무에서 다시 쓸 상황이 있었는지 묻되 실제 딜 정보는 기록하지 않는다.

## 기록할 항목

익명 참가자 A/B/C, 수행 날짜, 모바일/PC, 과업별 완료·도움 필요·중단, 소요 시간대(5분 이내/5~10분/10분 초과), 막힌 화면, 이해하기 어려웠던 문구만 남긴다. 응답은 공개 저장소가 아닌 운영자의 비공개 기록에 보관한다.

## 판정

- 3명 중 2명 이상이 도움 없이 첫 검토→PC 이어보기→저장을 완료한다.
- 3명 중 2명 이상이 다른 날짜에 저장한 검토를 다시 열고 수정한다.
- 기존 작업 손실·예시값 오인·계산 불일치는 인원수와 관계없이 먼저 고친다.
- 같은 단계에서 2명 이상 막히면 해당 동선을 다음 작업으로 선택한다.
- 외부 자료 재탐색 또는 수정 Excel 재입력이 공통 장애일 때만 해당 기능을 별도 설계한다.
- 자동 브라우저 검사 결과를 동료의 완료 기록으로 채우지 않는다. 표본 2~3명의 결과는 전체 방문자의 전환율이 아니다.
