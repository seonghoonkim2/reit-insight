# 01. 제품 개요

## 한 줄

**모델터(modelter.com)** — 한국 상업용 부동산(CRE) 재무모델을 웹에서 만들고, **수식이 살아있는 Excel 파일**을 그 자리에서 내려받는 단일 페이지 웹앱. 무료·회원가입 없음.

## 만든 사람 / 운영 형태

- 코람코자산신탁 상장리츠팀 현직자가 만든 **개인 프로젝트** (회사 제품 아님)
- **1인 운영.** 개발·기획·마케팅·데이터 판독 전부 혼자
- 수익화 없음. 광고 없음. 결제 없음
- 정규 근무 외 시간에 작업 → **투입 가능 시간이 가장 희소한 자원**

## 무엇을 대체하나

기존에는 이 일을 **엑셀 템플릿을 손으로 만들거나, 잘 만드는 사람에게 부탁**해서 했습니다.
모델터는 숫자 몇 개만 넣으면 IRR·DSCR이 화면에 바로 나오고, 같은 계산식이 든 엑셀을 즉시 받습니다.

## 딜 4종

| 딜 | 내용 | 엑셀 |
|---|---|---|
| 오피스 매입 | 매입가·임대료·Exit Cap → IRR·EM·DSCR | 13시트 |
| 물류센터 매입 | 위와 동일 엔진, 물류 관행 기본값(저운영비) | 13시트 |
| 개발·PF (공동주택 분양) | 평형별 분양가·중도금·브릿지→본PF 월별 엔진 | 6시트 |
| 리파이낸싱 | 차환 대안 3개 LTV·금리·DSCR 비교 | 4시트 |

준비 중(수요 수집 중): 호텔 · 리테일 · 임대주택 · 데이터센터

## 자본구조 (오피스·물류)

선순위 → **중순위(메자닌)** → 보증금 승계 → 우선주 → 보통주 5단.
중순위는 이자 지급 방식이 분기점 — `이자만 지급`(현금, DSCR 하락)과 `만기일시상환(이자 누적·PIK)`(잔액 증가, 매각 시 일괄).

## 사용자 (추정 — 로그로 직접 확인은 불가)

기관 부동산 실무자로 보입니다. 근거: 유입의 상당수가 Microsoft Teams(사내 메신저)와 LinkedIn, 딜 유형이 오피스·개발에 집중.

가정하는 4개 층:
- **본부장·팀장** — 보고 전 IRR·엑셀 초안이 그 자리에서 필요
- **시니어** — 가정만 바꿔 시나리오 검토 가속
- **주니어** — 검증된 구조 위에서 완성, 가정 검토에 집중
- **취준생·학생** — 실무 모델 구조를 직접 만들며 학습

## 기술 구조 (제약 이해용)

- **단일 HTML 파일** `dart-search/web/modelter/index.html` (895KB, gzip 271KB). 빌드 과정 없음, 프레임워크 없음, 의존성 없음
- Cloudflare Worker로 배포. master 푸시 → 자동 배포
- 서버는 정적 파일 + 익명 이벤트 수집(`/e`)만. **DB 없음, 로그인 없음, 세션 없음**
- 계산·엑셀 생성·PPT 생성 전부 **브라우저 안에서** 일어남
- 부가 페이지: `/guide`(용어사전 32개) · `/howto` · `/trust` · `/verification` · `/calc/*` 4면 · `/t/*` 32면 (검색 착지용, 자동 생성)

## 절대 못 바꾸는 것 (제안 시 유의)

1. **딜 데이터는 서버로 안 보냅니다.** 수집하는 건 이벤트명·딜 유형·기능 플래그·기기·유입 호스트뿐. 수치·임차인명·개인정보는 절대 전송 금지. → **계정·클라우드 저장·협업 기능은 이 원칙과 정면 충돌**합니다. 제안하려면 이 점을 먼저 다루세요.
2. **화면 수치 = 다운로드 엑셀.** 이걸 "파리티"라 부르고, 엑셀을 파이썬 수식 엔진으로 재계산해 자동 검증합니다(현재 11개 조합). 화면에만 있고 엑셀에 없는 계산은 만들지 않습니다.
3. **단일 파일 유지.** 빌드 도구 도입 안 함. 성능 예산: gzip < 300KB(현재 271KB), 렌더 블로킹 외부 CSS 0건.
4. **"투자 권유가 아닌 정보 제공 목적"** 고지 유지. 숫자 예시는 샘플이며 실제 시세 아님.
5. **1인 운영.** 지속적인 사람 손이 필요한 제안(콘텐츠 매주 발행, 커뮤니티 운영, 영업)은 현실성을 먼저 따져야 합니다.

## 현재 지표 체계

- **북극성**: 주간 **실사용 산출물** — "자기 숫자를 직접 넣은 세션"이 만든 산출물 수
- 퍼널: `session`(방문) → `activate`(직접 입력) → `computed`(자기 딜 결과 도달) → `output`(엑셀·PPT·공유 등)
- 가드레일(악화 시 기능 작업 중단): 파리티 통과 · 엔진 불변식 17건 · gzip < 300KB
