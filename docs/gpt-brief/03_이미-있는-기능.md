# 03. 이미 있는 기능 158개

**이 파일의 목적**: GPT가 이미 있는 걸 새 아이디어로 제안하는 걸 막기 위한 것입니다.
제안하기 전에 여기에 있는지 확인하세요. 있다면 "이미 있으니 **개선**"으로 방향을 바꾸세요.

아래는 자동 검증(CI)이 매 배포마다 존재를 확인하는 마커에서 뽑은 전수 목록입니다.

## 계산 엔진

- 오피스·물류 DCF 엔진 (`calcModel`) + 렌트롤 기반 엔진 (`leaseModelV2`) 2경로
- 공동주택 분양 월별 사업수지 엔진 (브릿지 → 본PF, 중도금 월별)
- 리파이낸싱 연도 전개 (`refiSchedule`) · 텀시트 비교
- 세후 IRR 계산 (도관/비도관 분기)
- 우선주 누적배당 워터폴
- **중순위(메자닌)** — 현금이자형 / 이자누적(PIK)형
- 보증금 승계 (조달 + 매각 시 성장 정산)
- 운용보수·고정비 · 중도상환수수료 · 매각성과보수
- 거치후 원리금균등 상환
- 변동 보유기간 (3~10년) 엑셀 재생성 (`holdTemplate`)
- 역산 솔버 (`mtBisect`) — 목표 IRR 매입가 역산 · 손익분기 Exit Cap · 손익분기 공실률
- 손익분기 분양률 · PF 상환한계 분양률 솔버
- 민감도 5×5 히트맵 (Exit Cap × 성장률/금리 축 토글)
- 시나리오 비교 (Base/보수/낙관 전 지표)

## 입력

- 딜 4종 탭 + 준비 중 4종 (수요 클릭 수집)
- 핵심 입력 우선 그룹 (5개만 넣으면 결과)
- 세부 항목 접기 (`fsub`) — 통상값 자동 적용
- 모델 깊이 3단 (빠른 검토 / 표준 / 심층)
- 입력 참고 범위 칩 (딜 유형별 시장 참고치, 출처·기준일 포함)
- 원화 환산 라이브 힌트 (억/조)
- 인라인 유효성 검증 + 오류 표시
- 핵심 입력 진행률 표시
- 표준값 채우기 · 예시 채우기 · 전체 비우기
- **내 기본값** 프리셋 (딜 유형별, 회사 표준 부대비·보수·대출 조건)
- **하우스 기준** (내 허들 IRR·DSCR 설정)
- 가정 출처·기준일 기록 (3경로 영속, 엑셀 가정 시트에 반영)
- 모바일 빠른 입력 위저드 (⚡핵심만)
- 미팅용 즉석 조정 바 (± 로 핵심 드라이버만 실시간)
- 렌트롤 업로드 + 행 단위 검증 + 매핑 확인 표 + 임차인명 마스킹
- **IM 추출** 3종: 무키 로컬 자동 인식 · IM 체크리스트 · AI 정밀 추출(BYOK, 본인 API 키)
- 사진(비전) IM 추출
- 매도자 제시치 대조

## 결과 화면

- KPI (IRR 세전/세후 · EM · 평균 배당률 · 언레버드 IRR · 최소 DSCR · 자기자본)
- **결과 자동 판정 코멘트** + 다운사이드 한 줄
- 자본구조 트랜치 블록 (금액·비중·금리·IRR·배당률)
- 부채 커버넌트 · 리파이 참고 (만기 차환 갭 테스트 포함)
- 연도별 현금흐름 표
- 임대차 리스크 카드 (렌트롤 사용 시)
- 즉시 점검 (가정 적정성 전수 점검 + 검토 질의서 초안)
- 미니 KPI 위젯 (스크롤 시 상단 고정)
- 첫 결과 코치마크 (1회)
- 결과 용어 → 용어사전 앵커 링크
- 방법론 모달 (가정·계산식 + 내 숫자 대입)
- 결과 빈 상태 안내 (누락 필드 지목)

## 산출물

- **엑셀** 13시트 (오피스·물류) / 6시트 (분양) / 4시트 (리파이) — 수식 살아있음
- **엑셀 자가 검증 스탬프** — 생성 시점 화면값 vs 파일 재계산 PASS/FAIL
- **엑셀 라운드트립** — 받은 엑셀을 드롭하면 딜 복원 (`_Restore` 숨김 시트)

- **AI 지시문** — Claude in Excel 등에 붙여넣을 프롬프트 자동 생성
- **한 줄 보고** (카톡용 요약 + 링크)
- **검토 메모 초안** (메일 본문)
- **딜 비교표 복사** · 파이프라인 보고 복사
- 원페이지 티저 모듈
