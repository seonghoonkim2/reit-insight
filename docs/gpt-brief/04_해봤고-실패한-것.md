# 04. 이미 해봤고 실패한 것

**이 파일의 목적**: 같은 실패를 반복하지 않기 위한 것입니다.
여기 있는 걸 다시 제안하려면 **"왜 이번엔 다를지"를 먼저** 말해 주세요.

## 실패 확정

### 1. 간이 모드 2종 — "골라야 보이는 간소화"는 안 팔린다

| 시도 | 결과 |
|---|---|
| `빠른 검토` 깊이 (1~3시트, 핵심 필드만) | 30일 **98건 / 3,754건 = 2.6%** |
| 모바일 위저드 (⚡핵심만, 큰 글씨로 차례로) | 30일 **6건** |

두 번 다 "간소한 버전을 옵션으로 준비"했는데 아무도 안 골랐습니다.

**진단**: 문제는 간소화가 아니라 **사용자가 선택해야만 보이는 옵션**이었다는 것.
**후속 조치**: 같은 핵심 필드 묶음을 **표준·심층에서도 맨 앞 그룹**으로 노출해 간소화를 기본 동선으로 만듦(2026-07). 이후 활성화율이 7.2% → ~13%로 올라 4주 유지.

**교훈**: "모드를 만든다"는 실패했고, "기본 동선을 바꾼다"는 성공했습니다.

---

### 2. 산출물 회수 루프 — 링크를 넣어도 안 돌아온다

엑셀 커버 시트·01_Assumptions·IC 원페이저 QR·PNG QR·PPT 하이퍼링크에 전부 "모델터로 돌아오기" 링크를 심었습니다.

| | 30일 |
|---|---|
| 엑셀 다운로드 | 156 |
| `src=xlsx` 재진입 | **5** (그중 활성화 0) |
| `recover_cta` 클릭 | **2** |

**진단**: 받은 사람이 파일을 여는 것과, 링크를 눌러 웹앱으로 오는 것 사이에 큰 간극이 있습니다. 이유는 계측되지 않습니다.

### 3. 첫 방문 역할 선택 팝업 — 제거함

"어떤 일을 하고 계신가요?" 4지선다 모달을 첫 방문에 띄웠습니다(30일 308건).

**문제**: LinkedIn 등 외부 유입이 착지하자마자 전체화면 모달이 제품을 가림. 링크드인 55세션에 활성화 0이던 시기가 있었습니다.
**중간 조치**: 모바일은 바텀시트로 바꿔 뒤에 예시 결과가 보이게 → 링크드인 활성화 0 → 3, 산출물 4 → 25로 개선.
**최종**: 2026-08-11 **팝업 자체를 전부 제거**(What's new 자동 노출도 중단). 효과는 아직 측정 전.

### 5. 시각적 리디자인 — 사용자가 거부

외부 참고 사이트를 벤치마킹한 프론트엔드 고급화 시안을 만들어 보여줬으나 **"별로다 하지말자"**로 중단. 배포하지 않음.

**교훈**: 이 제품에서 "더 멋있게"는 요구가 아닙니다. **가독성·전문성**은 환영받았습니다(같은 시기 UX 개선 프로토타입은 "가독성은 정말 매우 좋아진 것 같다"는 반응).

## 운영 규칙 (실패를 실패로 인정하기 위한 장치)

1. **사전 등록**: 기능을 만들기 전에 "성공/실패 판정 기준"을 먼저 적습니다. 예 — `빠른 검토 깊이가 4주 뒤 5% 미만이면 폐기`.
2. **데이터 전 선제 구현 금지**: 수요 증거 없이 큰 기능을 만들지 않습니다. 준비 중 딜은 "가짜 문"(클릭 수집)으로 수요를 먼저 잽니다.
3. **가드레일**: 파리티 통과·불변식 17건·gzip 300KB. 이게 깨지면 기능 작업을 멈추고 그것부터 고칩니다.

## 최근에 고친 실제 버그 (참고 — 제품 성숙도 감각용)

2026-08-10~11에 외부 벤치마크 대조로 산출물 결함 4건을 찾아 고쳤습니다.

- 무차입 딜에서 엑셀 파일이 **손상 파일로 거부**됨 (숫자 셀에 `null`)
- `#DIV/0!` · `#NUM!` 이 **표지 시트까지 노출**
- 조달 합계에 **승계 보증금이 빠져** 예시 딜 포함 **모든 오피스·물류 다운로드**가 검증 시트에 `Uses=Sources FAIL`·`종합 판정 FAIL(9/10)`을 달고 나감
- 중순위(메자닌)가 **켜도 계산에 안 들어가는 장식**이었음 → 실계산 편입

**교훈**: 화면 수치는 맞아도 산출물이 깨질 수 있습니다. 그래서 "수치 대조"에 더해 "파일이 열리는가 · 오류가 노출되지 않는가 · 파일이 스스로를 FAIL이라 말하지 않는가"를 전 딜 공통 게이트로 올렸습니다.
