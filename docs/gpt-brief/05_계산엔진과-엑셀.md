# 05. 계산 엔진과 엑셀 구조

계산 로직·모델링 방식을 얘기할 때만 필요한 파일입니다. UX·성장 얘기만 할 거면 건너뛰어도 됩니다.

## 핵심 원칙 — 파리티

**화면에 보이는 수치 = 다운로드한 엑셀이 재계산한 수치.**

엑셀은 값이 아니라 **수식**이 들어갑니다. 받은 사람이 가정 셀을 바꾸면 결과가 따라 움직입니다.
이걸 자동 검증합니다: 생성된 엑셀을 파이썬 `formulas` 수식 엔진으로 **독립 재계산**해 화면 엔진 값과 대조. 현재 **11개 조합** 전수 통과, 오차 1e-15 수준.

검증 조합: 오피스 · 물류 · 분양 · 리파이 + 경계 변형 7종(우선주 끔 · 비도관 · 보유 7년 · 무차입 · 공실 100% · 중순위 현금이자 · 중순위 PIK).

## 오피스·물류 엔진 (13시트)

```
매입가 = 평당 매입가 × 연면적
감정평가액 = 매입가 × 감정가 비율
Uses(총 취득원가) = 매입가 + 취득세 + 기타 취득부대비 + 금융 취급수수료

── 조달 (Sources) ──
선순위 대출   = 감정평가액 × 선순위 LTV
중순위(메자닌) = 감정평가액 × 중순위 LTV
보증금 승계    = 평당 월임대료 × 임대면적 × 임대율 × 보증금 개월수
우선주        = Uses × 우선주 비중
보통주(plug)  = Uses − 선순위 − 중순위 − 보증금 − 우선주
                                    ↑ 나머지를 메우는 잔여 항목

── 운영 (연도별) ──
EGI  = 임대료 + 관리비 + 기타수입 + 보증금 운용수익
NOI  = EGI − 운영비(PM·FM·수도광열·수선·기타·제세공과·보험)
운영현금흐름 = NOI − CapEx

── 부채 ──
선순위: 만기일시(이자만) / 원금균등 / 원리금균등 / 거치후 원리금균등
중순위: 이자만 지급(현금)        → 매기 현금 유출, 잔액 불변
        만기일시상환(이자 누적)  → 현금 유출 0, 잔액이 복리로 증가(PIK)
        원금은 두 방식 모두 매각 시 일괄

DSCR = NOI ÷ (선순위 이자+원금 + 중순위 현금이자)
ICR  = NOI ÷ (선순위 이자 + 중순위 발생이자)
Debt Yield = NOI ÷ (선순위 기말잔액 + 중순위 기말잔액)

── 매각 ──
매각가   = 익년 NOI ÷ Exit Cap
순매각가 = 매각가 × (1 − 매각비용률)
분배     = 순매각가 − 선순위 잔액 − 중순위 잔액 − 중도상환수수료
                    − 매각성과보수 − 보증금 반환(성장 반영)

── 워터폴 ──
분배가능현금 → 우선주 배당(누적/비누적) → 우선주 원금(매각 시) → 보통주 잔여

── 세무 ──
도관과세(리츠): 법인세 0
비도관: 과세소득 = NOI − 이자(발생주의, PIK 포함) − 감가상각 − 운용보수
        양도세 = (순매각가 − 장부가) × 세율
```

**지표**: 레버드 IRR(세전·세후) · Equity Multiple · 평균 배당수익률 · 언레버드 IRR · 최소 DSCR · 트랜치별 IRR

## 자가 검증 스탬프

엑셀 11시트에 **생성 시점의 화면 계산값을 고정**해 두고, 옆 칸에서 같은 지표를 파일 수식으로 재계산해 `PASS/FAIL`로 대조합니다.
받은 사람이 "이 파일이 화면과 같은 값인지", "누가 셀을 고쳤는지"를 파일 안에서 확인할 수 있습니다.

## 분양(개발·PF) 엔진 — 6시트

월별 엔진입니다. 브릿지 → 본PF 전환, 중도금 회차별 유입, 기성 곡선에 따른 공사비 지출, 분양률에 따른 수입 인식.
지표: 사업이익 · 사업이익률 · 필요 브릿지/본PF 한도 · Equity Multiple · 연환산 IRR · **손익분기 분양률** · **PF 상환한계 분양률**(이분법 반복 계산).

## 리파이낸싱 엔진 — 4시트

차환 대안 3개를 나란히: 대출금 · 1차년 DSCR · 최소 DSCR · 총이자 · 만기잔액. 기존 대출 상환·중도상환수수료·신규 취급수수료 반영.

## 품질 게이트 (매 배포)

1. 빌드 스탬프 → 파리티 공표 페이지 재생성 (4딜 실패 시 배포 중단)
2. 검색 착지면 38개 재생성 + 최신 여부 확인
3. CI 마커 158건 + 헤드리스 행동 검사
4. 엔진 경제 단조성 불변식 **17건** (예: LTV를 올리면 대출금은 단조 증가하고 DSCR은 단조 감소해야 한다)
5. 스모크 QA **47건** (실제 브라우저)
6. 파리티 11조합
7. 성능 예산 gzip < 300KB
8. 테스트 훅 유출 0

## 전 딜 공통 산출물 구조 검사 (2026-08-10 신설)

수치가 맞아도 파일이 깨지면 소용없다는 걸 실제 버그로 확인하고 추가했습니다.

| 검사 | 왜 |
|---|---|
| 숫자 셀에 비유한값 없음 | `null`·NaN이 들어가면 엑셀이 "손상된 파일"로 거부 |
| 엑셀 오류 토큰 0 | `#DIV/0!`·`#NUM!`이 표지까지 전파된 전례 2건 |
| 검증 시트 종합 판정 PASS | 파일이 스스로를 FAIL이라 말하면 안 됨 |

## 알려진 한계 (제안 시 참고)

- **월별 리스 엔진 없음** — 오피스·물류는 연간 단위. 임차인별 만기·렌트프리는 렌트롤 모드에서 부분 반영
- **CapEx가 정액 충당금** — 연도별 개별 계획 입력 없음
- **공실이 단일 비율** — 임차인별 만기 공백은 렌트롤 모드에서만
- **금리 시나리오 없음** — 변동금리·스왑 미반영
- **중순위 별도 취급수수료 미반영** (선순위 기준만)
- **다중 자산 포트폴리오 없음** — 딜 1건 단위
