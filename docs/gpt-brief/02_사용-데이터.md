## 데이터에 **없는** 것 (추측 금지)

- 사용자가 누구인지 (회사·직무·경력) — 물어본 적 없음
- 왜 이탈했는지 — 이탈 사유 계측 없음
- 재방문율 / 코호트 리텐션 — 사용자 식별을 안 하므로 산출 불가
- 엑셀을 받아서 **실제로 썼는지** — 다운로드까지만 보임
- 만족도 · NPS — 피드백 폼은 있으나 응답 거의 없음
- 세션 길이 · 스크롤 깊이 · 클릭 히트맵 — 계측 안 함
