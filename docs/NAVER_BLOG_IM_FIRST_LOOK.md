# 네이버 블로그 게시 원고 — IM 받은 직후 첫 숫자 15분

> 상태: 게시 전 초안. 외부 게시와 계정 작업은 운영자가 최종 확인한 뒤 진행한다. 실제 딜명·자산명·회사명·수치·임차인명·개인정보가 들어간 화면은 사용하지 않는다.

## 게시 세팅

- 제목: **상업용 부동산 IM 받았을 때, 첫 IRR·DSCR 15분 검토 순서**
- 썸네일 문구: **IM 받았으면 / 첫 숫자 15분**
- 설명 첫 문장: `IM·티저가 도착했을 때 완성형 모델부터 만들지 않고, 계속 볼 딜인지 판단할 첫 숫자를 뽑는 순서입니다.`
- 카테고리: 상업용 부동산 / 부동산 금융 / 실무 도구 중 기존 블로그 분류에 맞는 하나
- 해시태그: `#상업용부동산 #CRE #IM검토 #IRR #DSCR #CapRate #부동산금융 #재무모델`

## 게시용 본문

IM이나 티저가 도착하면 바로 완성형 엑셀부터 만들기 쉽습니다.

하지만 첫 15분의 목적은 투자심의 결론이 아닙니다. **계속 볼 딜인지, 무엇을 더 물어봐야 하는지 정할 첫 숫자**를 만드는 것입니다. 오피스·물류 매입 기준이라면 매입가, NOI, 대출, Exit 가정만 제대로 잡아도 첫 IRR·DSCR과 하방을 볼 수 있습니다.

### 1. 계산 전에 기준부터 맞춥니다

먼저 IM에서 세 가지를 확인합니다.

1) 자료 기준일이 언제인지

2) 금액 단위가 원·천원·백만원 중 무엇인지

3) 임대료·NOI가 현재 계약, 연환산, 안정화 기준 중 무엇인지

기준이 섞이면 계산은 정교해 보여도 출발점부터 틀립니다. 특히 보증금, 관리비, 렌트프리, 공실, 매각비용이 어느 숫자에 포함됐는지 메모해 두는 편이 좋습니다.

### 2. 첫 계산에 필요한 최소 가정만 찾습니다

오피스·물류 매입은 아래 다섯 묶음부터 봅니다.

- **가격:** 매입가와 취득 부대비용
- **수익:** 임대료 또는 NOI, 공실, 운영비
- **금융:** LTV, 금리, 상환 방식, 수수료
- **보유:** 보유기간과 매각비용
- **출구:** Exit Cap과 NOI 성장 가정

분양 사업이라면 토지비·연면적·분양가·공사비·사업기간·조달 조건, 리파이라면 자산가치·NOI·기존 잔액·신규 금리·LTV·만기를 먼저 찾습니다.

IM에 없는 값은 억지로 사실처럼 만들지 않습니다. 비어 있는 항목과 임시 가정을 구분해 두고, 첫 결과 뒤에 자료 요청 목록으로 바꾸면 됩니다.

딜 유형별로 IM에서 찾을 숫자를 한 장에 정리한 체크리스트:

https://modelter.com/im-checklist

### 3. 결과는 IRR 하나로 끝내지 않습니다

첫 결과는 다음 순서로 읽습니다.

**① 수익성**

레버드 IRR과 Equity Multiple이 요구수익의 방향에 맞는지 봅니다. IRR은 자기자본 현금흐름의 시간가치를 반영하고, Equity Multiple은 회수 총액을 직관적으로 보여 줍니다.

**② 부채 안정성**

DSCR이 어느 연도에 가장 낮아지는지 봅니다. `DSCR = 약정상 상환재원 ÷ 원리금 상환액`이지만, 실제 약정에서는 NOI·NCF·CFADS 정의와 원금 포함 여부가 다를 수 있으므로 텀시트 정의를 다시 확인해야 합니다.

**③ 출구 의존도**

Exit Cap을 높이고 NOI 성장을 낮춘 하방에서도 숫자가 버티는지 봅니다. 매각가 하나가 전체 수익의 대부분을 설명한다면 그 사실 자체가 다음 질문입니다.

**④ 화면과 산출물의 일치**

팀에 보낼 Excel의 수식과 화면 결과가 같은지 확인합니다. 첫 숫자가 빨라도 전달 과정에서 달라지면 다시 검증해야 합니다.

### 4. 팀에는 결론보다 가정과 다음 질문을 함께 올립니다

한 줄 보고는 아래 정도면 충분합니다.

`[1차 검토] 자산 유형 / 기준일 / 핵심 가정 / IRR·DSCR / 가장 큰 하방 / 추가 확인 2가지`

예를 들면 “현재 IM 기준으로 1차 검토했고, 공실과 Exit 가정이 결과를 가장 크게 움직입니다. 임대차 기준일과 대출 상환 조건 확인이 필요합니다”처럼 씁니다. 실제 숫자는 회사가 허용한 채널과 권한 범위 안에서만 전달합니다.

### 5. 모델터로 첫 숫자를 바로 뽑는 방법

모델터는 제가 반복하던 CRE 첫 검토를 줄이려고 만든 무료 개인 프로젝트입니다. 설치와 회원가입 없이 브라우저에서 계산하고, 화면과 같은 수식이 살아 있는 Excel을 내려받을 수 있습니다.

오피스 첫 계산 바로 열기:

https://modelter.com/#t=office&src=sns

다른 딜 유형:

- 물류센터: https://modelter.com/#t=logistics&src=sns
- 공동주택 분양: https://modelter.com/#t=dev&src=sns

입력한 딜 수치는 계산을 위해 모델터 서버로 전송되지 않습니다. 다만 사용자가 직접 만드는 공유 링크에는 입력 가정이 들어가며 암호화된 보관함이 아니므로, 권한 있는 팀 채널에서만 사용해야 합니다.

첫 계산은 투자 권유나 투자심의 모델을 대신하지 않습니다. 화면과 글의 숫자·범위는 샘플이며 실제 시세가 아닙니다. 실사 자료, 약정 정의, 법률·세무 검토와 회사별 기준으로 다시 확인해 주세요.

## 이미지 4장 지시

모든 화면은 샘플 모드로만 캡처하고 브라우저 주소창·알림·계정 정보는 자른다.

1. 기존 `og.png` 또는 홈 첫 화면 — 대체텍스트: `상업용 부동산 첫 숫자를 계산하는 모델터`
2. `/im-checklist`의 기준·단위와 딜별 최소 입력 구간 — 대체텍스트: `상업용 부동산 IM 검토 체크리스트`
3. 오피스 샘플의 첫 입력과 결과 카드가 함께 보이는 화면 — 대체텍스트: `매입가와 NOI 가정으로 IRR과 DSCR을 확인하는 화면`
4. 결과 아래 `팀에 1차 검토 공유`와 `/verification`의 화면=Excel 검증 배지 — 대체텍스트: `첫 숫자를 팀에 전달하고 화면과 Excel 일치를 확인하는 과정`
