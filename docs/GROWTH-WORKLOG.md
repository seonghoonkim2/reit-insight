- 최종 빌드의 필수·관련 로컬 검사 13단계를 통과했다. 기록은 `gates4/summary.json`에 있다. 4개 딜 독립 엑셀 재계산, 앱 CI, 불변식 17건, 스모크 89건, 결과 저장 56건, 개인정보 등을 포함한다. 모바일 근사 첫 결과는 4,057ms로 5,000ms 이내이고 gzip은 306,196바이트로 기존 예산 이내다. HTML·CSS 변경에 맞춰 새로운 영구 테스트는 추가하지 않았다. 원격 필수 CI는 PR #148의 이번 커밋으로 확인한다.
- 독립 검토의 문구·기본값·JavaScript·클릭·키보드·동일 링크 확인 14개는 `recover-opt-independent.json`에 있다. 숨김 수정 후 빈 결과·유효 결과 복귀·읽기 전용 3상태는 `recover-opt-final-independent.json`에서 최종 소스로 다시 확인했다. 두 소스 사이의 차이가 숨김 CSS 한 줄과 빌드 스탬프뿐인 점도 기록했다.

## 다음 작업 순서

1. **사용 안내**: `/howto`를 수정→버전 저장→재방문→이전 조건 비교→읽기 전용 공유 한 흐름으로 정리한다. 딜별 엑셀 편집 범위와 실제 예시 CTA를 맞춘다. 준비된 `next-howto.patch`는 첫 저장 단순화 이전 자료이므로 현재 ‘이 조건 저장’과 이름 한 번 입력하는 동작에 맞는지 확인한 뒤 적용한다. 앱 동작과 다른 설명을 늘리지 않는다.
2. **NOI 설명**: `/t/noi`에 연 NOI만 있을 때의 입력 방법과 단위를 추가한다. 기존 `seo` 합산 로그에서 해당 페이지의 개별 효과를 분리할 수 없음을 유지한다.
3. **운영 효과 관찰**: 실제 운영 반영 UTC 시각을 기준으로 앞뒤 정확한 28일 창을 고정한다. 모든 지표는 절대기간 SQL로 조회하고 활성 세션 산출물은 기존 AE `blob11`로 분해한다. 조회할 수 없으면 보류한다. 사람 단위 재방문과 실제 업무 기회를 이벤트 수로 대신하지 않는다.

필요 없는 큰 기능, 검색 페이지 증산, 새 가입 절차, 실제 딜 정보 수집은 추가하지 않는다. 승인 대기 중에도 독립적인 수정·미리보기·배포 후 확인 절차를 이어가되 master 병합과 외부 게시를 하지 않는다.
