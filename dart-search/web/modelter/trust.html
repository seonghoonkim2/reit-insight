딜 데이터는 이 브라우저를
떠나지 않습니다.

모델터의 기본 계산·저장·Excel 생성은 매입가·임대료·렌트롤 같은 딜 정보를 서버로 보내지 않고 사용자 브라우저 안에서 일어납니다. 사용자가 직접 선택하는 AI 정밀 추출과 의견 전송의 외부 통신은 아래에 별도로 공개합니다. 이 문서는 팀장·정보보호팀 검토에 그대로 제출할 수 있도록, 무엇을 수집하고 무엇을 절대 수집하지 않는지와 직접 확인하는 방법을 정리한 것입니다.

한 줄 원칙 — 기본 계산에서 입력한 숫자는 전송되지 않는다. 자동으로 보내는 것은 익명 사용 통계(어떤 버튼을 눌렀는지)뿐입니다. AI 정밀 추출·의견 보내기는 사용자가 눌렀을 때만 각각 명시된 외부 서비스로 전송됩니다.
무엇을 수집하나 직접 확인하기 AI 추출(BYOK) 흐름 의견 전송 흐름 저장·공유 보안 헤더 만든 사람

무엇을 수집하고, 무엇은 절대 수집하지 않나

기본 계산 흐름에서 모델터 서버로 보내는 데이터는 익명 사용 이벤트(/e)뿐입니다. 목적은 "어떤 기능이 실제로 쓰이는지"를 보는 것이며, 아래가 /e로 전송되는 필드의 전부입니다. 이 표는 코드(worker.js)의 실제 수집 필드와 자동 검증으로 1:1 일치가 강제됩니다. 사용자가 선택하는 AI·의견 전송은 별도 절에서 다룹니다.

익명 사용 통계(/e)가 절대 수집·전송하지 않는 것

  • 매입가·임대료·NOI·대출 조건 등 모든 딜 수치
  • 임차인 실명·렌트롤 원본·업로드한 파일 내용
  • 이름·이메일·전화번호·로그인·쿠키 추적 식별자
  • IP 주소 원본(국가 코드만 받고 IP는 저장하지 않음)

저장 위치: 익명 이벤트는 Cloudflare(Workers Logs·Analytics Engine)에 집계용으로만 기록됩니다. 딜 데이터는 애초에 전송되지 않으므로 그 어디에도 없습니다.

믿지 말고 — 직접 확인하세요

주장만으로는 부족하죠. 브라우저 개발자 도구로 실제 오가는 통신을 5분 안에 직접 볼 수 있습니다. (크롬·엣지·웨일 기준)

  1. 모델터를 연 상태에서 키보드 F12를 눌러 개발자 도구를 엽니다.
  2. 상단 탭에서 Network(네트워크)를 선택합니다.
  3. 매입가·임대료 등 딜 숫자를 입력하고 엑셀을 받아 봅니다. 네트워크 목록에서 딜 숫자가 담긴 요청이 없다는 것을 확인하세요 — 기본 계산 중 모델터 서버로 가는 것은 /e(익명 이벤트)뿐이고, 그 Payload에는 위 표의 필드만 들어 있습니다. AI 정밀 추출·의견 보내기를 직접 누르면 아래에 공개한 외부 요청이 추가됩니다.
  4. 비행기 모드(오프라인)로 바꿔도 계산·엑셀 생성이 그대로 동작합니다 — 서버가 없어도 되기 때문입니다.

회사 정책상 외부 통신 자체를 막아야 한다면, 로드 후에는 네트워크 없이도 전 기능이 동작하므로 문제되지 않습니다(익명 이벤트 /e가 차단돼도 계산에는 영향 없음).

AI 가정 추출(선택 기능)의 데이터 흐름

IM 문서에서 가정을 자동으로 뽑는 기능은 두 가지입니다. 기본은 키·전송 없이 브라우저 안에서만 처리되고, 정밀 추출을 원할 때만 본인 API 키로 AI를 씁니다.

① 무키 자동 인식 (기본)

붙여넣은 텍스트를 브라우저 안에서 규칙 기반으로 해석합니다. 네트워크를 전혀 쓰지 않습니다 — 텍스트가 어디로도 전송되지 않고, 인식 후 버려집니다.

② AI 정밀 추출 (선택 · 본인 키)

브라우저→api.anthropic.com ✕ 모델터 서버 미경유

IM 텍스트·이미지와 API 키가 사용자 브라우저에서 Anthropic으로 직접 전송됩니다. 모델터 서버는 이 통신 경로에 없습니다. API 키는 메모리에만 두거나(선택 시 이 탭 세션에만) 저장하며, localStorage·공유 링크·저장본에 절대 담기지 않습니다. 사용료는 본인 Anthropic 계정에 청구됩니다. 문서 반출·외부 API 사용은 사내 정책을 먼저 확인하세요.

의견 보내기(선택)의 데이터 흐름

브라우저→api.web3forms.com→제작자 이메일 ✕ 모델터 서버 미경유

홈 하단에서 의견 보내기를 누른 경우에만 작성한 의견과 선택 입력한 회신 이메일이 Web3Forms로 직접 전송됩니다. 실제 딜명·자산명·수치·임차인명·회사명은 적지 않도록 입력 화면에 고지하며, 금액·면적·비율·연락처처럼 보이는 내용은 전송 전에 브라우저가 한 번 더 경고합니다. 이 선택 기능을 쓰지 않으면 해당 통신은 없습니다.

오프라인 동작

페이지 로드 이후 계산·엑셀 생성·공유 링크 생성은 네트워크 없이 동작합니다 — 저장소의 tools/qa/offline.js를 실행하면 누구나 브라우저 자동화로 재현할 수 있습니다. 네트워크가 끊기면 익명 사용 통계(/e)는 조용히 실패하고, AI 정밀 추출·의견 보내기 같은 선택 통신만 사용할 수 없습니다. 핵심 계산에는 아무 영향이 없습니다.

브라우저 저장과 공유 링크

딜을 저장하면 사용자 브라우저(localStorage) 에만 보관됩니다 — 서버 계정이 없습니다. 공유 링크는 입력값을 링크 문자열 안에 압축해 담고(서버 저장 없음), 링크를 받은 사람은 그 링크 안의 데이터로만 화면을 봅니다. 공유·산출물에는 임차인 실명이 자동으로 마스킹(임차인 A·B…)되어 담깁니다.
