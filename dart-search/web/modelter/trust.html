딜 데이터는 이 브라우저를
떠나지 않습니다.

기본 계산, 저장, Excel 생성은 브라우저 안에서 처리됩니다. 매입가, 임대료, 렌트롤 같은 딜 정보는 모델터 서버로 보내지 않습니다. AI 정밀 추출과 의견 보내기는 사용자가 직접 선택한 경우에만 아래에 적힌 외부 서비스와 통신합니다. 팀장이나 정보보호 담당자가 확인할 수 있도록 수집 항목과 확인 방법을 정리했습니다.

기본 계산에서 입력한 숫자는 전송되지 않습니다. 자동으로 보내는 정보는 어떤 기능이 쓰였는지 확인하기 위한 익명 사용 통계뿐입니다.

수집하는 정보와 수집하지 않는 정보

기본 계산 중 모델터 서버로 보내는 데이터는 익명 사용 이벤트(/e)뿐입니다. 어떤 기능이 실제로 쓰이는지 확인하기 위한 정보이며, 아래 표가 /e로 전송되는 필드의 전부입니다. 표와 코드(worker.js)가 일치하는지도 자동으로 검사합니다. AI 정밀 추출과 의견 보내기는 별도 절에서 설명합니다.

익명 사용 통계(/e)에 포함하지 않는 정보

  • 매입가·임대료·NOI·대출 조건 등 모든 딜 수치
  • 임차인 실명·렌트롤 원본·업로드한 파일 내용
  • 이름·이메일·전화번호·로그인·쿠키 추적 식별자
  • IP 주소 원본(국가 코드만 받고 IP는 저장하지 않음)

익명 이벤트는 Cloudflare Workers Logs와 Analytics Engine에 집계용으로 기록됩니다. 딜 데이터는 모델터 서버에 전송되거나 저장되지 않습니다.

브라우저에서 직접 확인하는 방법

Chrome, Edge, Whale의 개발자 도구에서 실제 통신 내용을 확인할 수 있습니다.

  1. 모델터를 연 상태에서 키보드 F12를 눌러 개발자 도구를 엽니다.
  2. 상단 탭에서 Network(네트워크)를 선택합니다.
  3. 매입가·임대료 등 딜 숫자를 입력하고 Excel을 내려받습니다. 네트워크 목록에 딜 숫자가 들어 있는 요청이 없는지 확인하세요. 기본 계산 중 모델터 서버로 보내는 요청은 /e뿐이며, Payload에는 위 표의 필드만 들어 있습니다. AI 정밀 추출이나 의견 보내기를 직접 선택하면 아래에 적힌 외부 요청이 추가됩니다.
  4. 네트워크를 끊은 뒤에도 계산과 Excel 생성이 동작하는지 확인합니다.

페이지를 불러온 뒤 네트워크를 끊어도 계산과 Excel 생성은 사용할 수 있습니다. 익명 이벤트 /e가 차단돼도 계산에는 영향이 없습니다.

AI 가정 추출(선택 기능)의 데이터 흐름

IM 문서에서 가정을 찾는 방법은 두 가지입니다. 기본 자동 인식은 브라우저 안에서만 처리합니다. AI 정밀 추출을 선택한 경우에만 본인 API 키를 사용합니다.

① 무키 자동 인식 (기본)

붙여넣은 텍스트를 브라우저 안에서 규칙 기반으로 해석합니다. 네트워크를 사용하지 않으며 텍스트는 인식 후 버립니다.

② AI 정밀 추출 (선택 · 본인 키)

브라우저→api.anthropic.com ✕ 모델터 서버 미경유

IM 텍스트·이미지와 API 키는 사용자 브라우저에서 Anthropic으로 직접 전송됩니다. 모델터 서버를 거치지 않습니다. API 키는 메모리에 두거나 사용자가 선택한 경우 이 탭의 sessionStorage에만 보관하며, localStorage·공유 링크·저장본에는 담기지 않습니다. 사용료는 본인 Anthropic 계정에 청구됩니다. 문서 반출과 외부 API 사용에 관한 사내 정책을 먼저 확인하세요.

의견 보내기(선택)의 데이터 흐름

브라우저→api.web3forms.com→제작자 이메일 ✕ 모델터 서버 미경유

홈 하단에서 의견 보내기를 누른 경우에만 작성한 의견과 선택 입력한 회신 이메일이 Web3Forms로 직접 전송됩니다. 실제 딜명·자산명·수치·임차인명·회사명은 적지 않도록 입력 화면에 고지하며, 금액·면적·비율·연락처처럼 보이는 내용은 전송 전에 브라우저가 한 번 더 경고합니다. 이 선택 기능을 쓰지 않으면 해당 통신은 없습니다.

오프라인 동작

페이지를 불러온 뒤에는 계산, Excel 생성, 공유 링크 생성이 네트워크 없이 동작합니다. 저장소의 tools/qa/offline.js로 같은 조건을 재현할 수 있습니다. 오프라인에서는 익명 사용 통계(/e), AI 정밀 추출, 의견 보내기만 동작하지 않습니다.

브라우저 저장과 공유 링크

저장한 딜은 사용자 브라우저(localStorage)에만 남습니다. 공유 링크에는 입력값을 링크 문자열 안에 압축해 넣으며 서버에는 저장하지 않습니다. 공유 링크와 산출물에서는 임차인 실명을 자동으로 마스킹(임차인 A·B…)합니다.

공유 링크의 압축은 암호화가 아닙니다. 링크를 가진 사람은 딜명·입력 가정·계산 결과를 볼 수 있고, 전체 링크가 브라우저 방문 기록이나 메일·메신저 로그에 남을 수 있습니다. 사내 정보 반출 정책을 확인하고 권한 있는 채널로만 보내세요. 매우 민감한 딜은 공유 링크·QR을 사용하지 말고, 산출물의 「이 모델 열기」 옵션도 끄세요.
