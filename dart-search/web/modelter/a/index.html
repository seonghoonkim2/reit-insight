       Claude in Excel이 처음이신가요?
      

        
Claude in Excel은 Microsoft Excel 안에서 Claude를 사이드 패널로 띄워 쓰는 기능입니다. 이 프롬프트를 그 패널에 붙여넣으면, Claude가 시트를 직접 만들어 줍니다.

        
    
          
  1. Excel에서 Claude 패널을 엽니다. (설치·접속 방법은 "Claude in Excel"로 검색해 안내를 참고하세요.)
    2. 
          
  2. 위 전체 복사 버튼을 누릅니다.
    3. 
          
  3. Claude 패널 입력창에 붙여넣고 보냅니다.
    4. 
          
  4. Claude가 한 시트씩 모델을 만들어 줍니다. 중간 질문에는 답해 주세요.
    5. 
        

        
Excel용 Claude가 없다면, 복사한 프롬프트를 일반 Claude(claude.ai) 대화창에 붙여넣어 모델 설계안을 받아볼 수도 있습니다.
