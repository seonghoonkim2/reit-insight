0. 숫자보다 먼저: 기준과 단위

기준일과 단위를 틀리면 정교한 모델도 첫 줄부터 어긋납니다. 자료 표지나 주석에 아래 네 가지부터 적으세요.

  • 자료 기준일임대차·감정평가·차입 조건이 어느 날짜 기준인지
  • 금액 단위원·천원·백만원·억원 중 무엇인지
  • 면적 기준㎡/평, 연면적(GFA)/임대면적(NLA) 구분
  • 수치 성격실적·예산·매도자 추정·운용사 가정 구분
모델터 입력 단위: 금액은 백만원(1,200억원 → 120,000), 면적은 평(㎡ ÷ 3.3058), 임대료·관리비는 임대면적 기준 평당 월 원입니다. 페이지의 숫자 예시는 설명용 샘플이며 실제 시세가 아닙니다.

1. 매입 딜 공통: IM에서 찾을 숫자

오피스·물류 매입 첫 계산의 뼈대입니다. 최소 표시만 있어도 모델터의 표준가정과 함께 1차 결과를 볼 수 있습니다.

자산 · 거래

표지, Investment Highlights, Transaction Overview

  • 매입가 또는 희망가최소부가세·취득부대비 포함 여부 별도 표시
  • 연면적·임대면적최소연면적과 NLA를 섞지 않기
  • 감정가·준공연도LTV 기준과 CapEx 가능성 점검
  • 거래 구조·예상 일정자산/지분 거래, 계약·잔금 예정일

수익 · 임대차

Rent Roll, Operating Statement, Leasing Assumptions

  • 현재 임대료 또는 연 NOI최소관리비 포함 여부와 기준 기간 확인
  • 공실률·렌트프리·운영비율현황과 안정화 가정을 분리
  • 임대료·NOI 성장률계약상 인상률과 시장 가정을 구분
  • WALE·상위 임차인·만기 집중실명 대신 집중도와 만기만으로도 첫 위험 점검 가능

금융 · 자본구조

Financing Assumptions, Sources & Uses

  • LTV·대출금최소매입가 기준인지 감정가 기준인지
  • 금리·상환 방식최소고정/변동, 이자만/분할상환, 수수료
  • 만기·리파이 가정보유기간보다 먼저 도래하는지
  • 보증금·우선주·메자닌승계 금액, 우선배당, 현금이자/PIK 구분

Exit · 하방

Exit Assumptions, Sensitivity

  • 보유기간최소대출 만기·임대차 만기와 함께 보기
  • Exit Cap최소진입 Cap보다 낮으면 공격적 가정인지 확인
  • 매각 비용·CapEx·TI/LC첫 계산에서 빠지기 쉬운 현금 유출
  • 하방 시나리오Exit Cap 상승, 공실 확대, 금리 상승 중 최소 하나

3. 결과가 나오면 이 순서로 읽기

수익성

IRR·EM 또는 사업이익률이 내부 목표와 얼마나 떨어져 있는지

상환 여력

최소 DSCR·Debt Yield 또는 PF 상환한계가 어디서 무너지는지

하방

Exit Cap·공실·금리·분양률이 나빠질 때 결과 범위가 어떻게 되는지

빈칸

표준가정으로 남은 항목 중 결과를 가장 크게 움직이는 3가지를 질문으로 전환

멈춤 기준: 결과가 좋아 보여도 자료의 기준일·단위가 불명확하거나 핵심 수익이 매도자 추정에만 기대면 “좋은 딜”로 결론 내리지 않습니다. 첫 계산의 역할은 결론보다 다음 질문을 정확히 만드는 것입니다.

4. 팀에 올릴 1차 검토 한 줄

숫자만 보내지 말고 기준 가정 → 첫 결과 → 하방 → 빠진 자료 순서로 붙이세요. 모델터 결과 아래 “팀에 1차 검토 공유”에서 같은 구조를 바로 만들 수 있습니다.

복사해 쓸 수 있는 형식
[모델터] 1차 검토
· 기준: 매입가 [ ] / NOI 또는 임대료 [ ] / LTV·금리 [ ] / Exit Cap [ ]
· 첫 결과: IRR [ ] / EM [ ] / 최소 DSCR [ ]
· 하방: Exit Cap 또는 공실·금리 스트레스 시 [ ]
· 확인 필요: [자료에 없거나 결과를 크게 움직이는 가정 1~3개]
· 첨부: 읽기 전용 링크 또는 수식 Excel

공유 링크는 암호화된 보관함이 아니라 입력값이 들어 있는 전달 수단입니다. 임차인명은 자동 마스킹되지만, 링크는 권한 있는 팀 채널로만 보내세요. 자세한 데이터 흐름은 보안·개인정보에서 확인할 수 있습니다.

자주 묻는 질문

IM에 없는 숫자는 어떻게 하나요?

억지로 추정하지 말고 비워 두세요. 모델터의 자산 유형별 표준가정으로 첫 계산을 한 뒤, 팀에 전달할 때 어떤 값이 표준가정인지 밝히고 자료 요청 목록으로 바꾸면 됩니다.

첫 계산은 투자심의 모델을 대신하나요?

아닙니다. 첫 계산은 검토를 계속할지와 무엇을 더 물어볼지 정하는 1차 스크리닝입니다. 실사 자료, 법률·세무 검토, 회사별 투자심의 기준으로 다시 검증해야 합니다.

화면 수치와 Excel이 같은가요?

모델터는 실제 수식 엔진으로 다운로드 Excel을 재계산해 화면과 일치하는지 검사합니다. 최근 검증 결과와 재현 방법은 파리티 검증에서 공개합니다.

입력한 딜 숫자가 서버로 전송되나요?

계산을 위해 입력한 딜 수치는 브라우저 안에서 처리되며 모델터 서버로 전송되지 않습니다. 단, 사용자가 직접 만든 공유 링크에는 입력값이 포함되므로 권한 있는 채널로만 전달해야 합니다.
