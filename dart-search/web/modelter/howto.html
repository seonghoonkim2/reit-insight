IM 받았으면, 첫 숫자 15분 — 팀 검토까지 30분

매도자 IM·티저가 도착하면 엑셀을 새로 짜기 전에 매입가·임대료/NOI·대출·Exit Cap부터 넣으세요. 첫 IRR·DSCR·하방을 확인하고, 팀에서 “이거 모델터로 돌려봤어?”라고 물을 때 1차 검토 링크와 수식 Excel로 바로 답하는 순서입니다. 설치·가입이 없고 딜 숫자는 모델터 서버로 전송되지 않습니다. IM에서 어떤 숫자를 찾아야 할지 막히면 IM 검토 체크리스트, 용어가 낯설면 용어사전부터 보세요.

1딜 유형과 구조 확인 · 1분

오피스·물류·분양·리파이 중 지금 받은 딜을 고르세요. 기본 예시가 채워져 있어 입력 항목과 결과 구조를 먼저 확인할 수 있습니다.

예시 딜(강남 A타워·판교 A지구·분당 B빌딩)은 실제 시세가 아닌 샘플이지만, 입력 항목과 결과 구조를 익히기엔 충분합니다. 어떤 값이 결과를 크게 움직이는지 임대료·Exit Cap을 바꿔보며 확인해 보세요.

2내 딜 숫자 넣기 · 5~10분

방법은 세 가지 — 상황에 맞게 고르세요. 어떤 방법이든 금액 입력엔 억·조 환산이 바로 붙어 단위 실수를 막아줍니다.

A. 폼에 직접 입력

핵심 입력엔 시장 참고 범위(예: 서울 오피스 Exit Cap 4.0~5.5%, 물류 5~7%)가 붙어 있어 기준점을 잡기 쉽습니다. 미입력 항목은 자산 유형별 표준가정으로 계산됩니다.

B. 모바일이면 ⚡핵심만 위저드

이동 중이라면 입력 패널의 ⚡ 핵심만 버튼을 누르세요. 핵심 입력을 한 개씩 큰 글씨로 물어보고, 마지막에 KPI 미리보기와 자동 판정까지 보여줍니다.

C. IM 텍스트로 자동 추출 β

오피스·물류 폼 상단 🤖 IM에서 가정 추출 — IM의 매매 개요·임대차 현황을 붙여넣고 본인 Anthropic API 키를 넣으면 매입가·연면적·임대료·Exit Cap 등 12개 항목을 추출해 줍니다. 추출값은 자동 적용되지 않고 현재값과 나란히 검토 표로 나와, 체크한 항목만 채워집니다.

보안: 텍스트와 키는 브라우저에서 api.anthropic.com으로만 직접 전송되며 모델터 서버는 거치지 않습니다. 키는 저장되지 않습니다(선택 시 탭 세션만). 문서 반출에 대한 사내 보안 정책을 먼저 확인하세요.

3결과 읽기 · 3분

숫자를 바꾸는 즉시 결과가 갱신됩니다. 화면 수치는 내려받는 엑셀과 같은 계산식에서 나옵니다(파리티 검증).

자동 판정이 먼저 말해줍니다

결과 카드 상단의 판정 한 줄이 통상 기준과 비교해 줍니다:

4리스크 점검 · 5분

기본 시나리오가 좋아 보여도, 가정이 틀어졌을 때 얼마나 버티는지가 심의의 핵심 질문입니다.

민감도 히트맵

Exit Cap × 성장률(또는 선순위 금리) 5×5 조합의 레버드 IRR을 한눈에. 분양 사업이면 분양률 × 분양가 조합의 사업이익률과 손익분기·PF 상환한계 분양률을 봅니다.

렌트롤 업로드 (오피스·물류)

임차인별 계약을 붙여넣으면 현 계약·공실 해소·만기 롤오버를 분해해 연도별 NOI로 전개하고, WALE·만기 집중·최대 임차인 비중 같은 임대차 리스크를 자동 산출합니다. 임차인 실명은 화면·엑셀·공유에서 가릴 수 있습니다.

대주 관점 (분양·PF)

시행↔대주 뷰를 전환하면 필요한 브릿지·본PF 한도와 분양률 스트레스 시 상환 안전성을 대주 심사 관점에서 보여줍니다.

5팀에 1차 검토 공유 · 2분

첫 숫자가 나오면 결과 아래의 “팀에 1차 검토 공유”에서 한 줄 보고나 읽기 전용 링크를 먼저 보내고, 필요한 산출물로 이어갑니다.

  • 한 줄 보고 복사 — `[모델터] 1차 검토`로 시작하는 딜명·핵심 KPI·판정·읽기 전용 링크. 카톡·메일 보고용.
  • 공유 링크 — 읽기 전용(결과만) 또는 편집용. 서버 저장 없이 링크 안에 담기고 임차인명은 자동 마스킹.
  • 13시트 엑셀 — 수식이 살아있는 재무모델. 화면 수치와 일치함을 수식 엔진 재계산으로 검증(파리티).
  • IC 패키지 PPT 7장 — 표지·투자 요약(KPI 타일·자동 판정)·자본 구조·핵심 가정·현금흐름·민감도 히트맵·리스크 점검.
  • 원페이지 티저 — 1장짜리 간이 검토 보고(PPT 양식).

인쇄(📄 요약)를 누르면 IC 원페이저 형태로도 뽑을 수 있습니다.

6저장 · 버전 관리 · 1분

딜을 저장하면 이 브라우저에 버전이 쌓입니다(v0.1, v0.2 …). 대출 조건이 바뀌거나 렌트롤이 갱신될 때 버전을 저장해 두면, 나중에 그 버전 기준으로 엑셀·티저를 다시 뽑을 수 있고 버전 간 비교(최고 IRR·지표별 최적값 강조)도 됩니다. 팀 PC로 옮길 땐 .modelter 파일로 내보내기.

자주 묻는 질문

딜 정보가 외부로 나가지 않나요?

계산·저장 모두 브라우저 안에서 이뤄지고 모델터 서버로는 딜 수치가 전송되지 않습니다. 유일한 예외는 본인이 선택한 IM 추출(β)로, 이때도 본인 API 키로 Anthropic에 직접 전송될 뿐 모델터 서버는 거치지 않습니다.

화면 숫자와 엑셀이 다르면 어떡하죠?

같은 계산식에서 나오도록 만들었고, 실제 수식 엔진으로 엑셀을 재계산해 화면과 일치하는지 상시 검증합니다. '화면 = 다운로드 엑셀' 배지가 그 표시입니다. 차이를 발견하면 제보해 주세요.

팀원이 결과를 보려면 설치가 필요한가요?

아니요. 읽기 전용 공유 링크를 보내면 받는 사람은 브라우저에서 바로 결과·민감도를 볼 수 있습니다. 수정하고 싶으면 '내 모델로 열기'를 누르면 됩니다.
