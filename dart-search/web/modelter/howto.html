1딜 유형과 예시 확인 · 1분

오피스·물류·분양·리파이 중 해당하는 유형을 고릅니다. 기본 예시로 입력 항목과 결과를 먼저 확인할 수 있습니다.

강남 A타워, 판교 A지구, 분당 B빌딩은 실제 시세가 아닌 샘플입니다. 임대료나 Exit Cap을 바꿔 어떤 값이 결과에 크게 영향을 주는지 확인하세요.

2내 딜 숫자 넣기 · 5~10분

입력 방법은 세 가지입니다. 금액을 넣으면 억·조 단위 환산값도 함께 표시됩니다.

A. 폼에 직접 입력

입력란의 참고 범위와 기본값은 예시입니다. 시점·입지·자산에 따라 다르므로 실제 자료와 대조하세요. 빈칸에 적용된 기본값도 함께 확인합니다.

B. 모바일에서 하나씩 입력

이동 중이라면 입력 패널의 ⚡ 핵심만 버튼을 누르세요. 큰 글씨로 한 항목씩 입력하고, 마지막에 주요 지표와 판정을 확인합니다.

C. IM 텍스트 자동 인식

오피스·물류에서 “도구 · AI 모델 깊이” 안의 “IM에서 숫자 가져오기”를 열고 IM 붙여넣기 → 자동 인식을 선택하세요. 매입가, 연면적, 임대료, Exit Cap 등을 찾으면 원문과 대조한 뒤 필요한 항목만 반영합니다. 복잡한 문서는 본인 Anthropic API 키로 AI 정밀 추출(β)을 사용할 수 있습니다.

기본 자동 인식은 네트워크를 사용하지 않습니다. AI 정밀 추출을 선택하면 IM 텍스트와 API 키가 브라우저에서 api.anthropic.com으로 직접 전송되고 모델터 서버는 거치지 않습니다. 문서 반출과 외부 API 사용에 관한 사내 정책을 먼저 확인하세요.

3결과 읽기 · 3분

숫자를 바꾸면 결과도 바로 바뀝니다. 화면과 다운로드 엑셀은 같은 계산식을 사용합니다.

주요 지표와 참고값을 확인합니다

4리스크 점검 · 5분

가정을 보수적으로 바꿨을 때 수익률과 상환 여력이 얼마나 줄어드는지 확인합니다.

민감도 히트맵

5×5 표에서 Exit Cap과 성장률(또는 선순위 금리)에 따른 레버드 IRR 변화를 확인합니다. 분양 사업은 분양률과 분양가에 따른 사업이익률, 손익분기·PF 상환한계 분양률을 봅니다.

렌트롤 업로드 (오피스·물류)

임차인별 계약을 붙여넣으면 계약 만기와 공실의 재임대 가정을 반영해 연도별 NOI를 계산합니다. WALE, 만기 집중, 최대 임차인 비중도 함께 봅니다. 임차인 실명은 화면·엑셀·공유에서 가릴 수 있습니다.

대주 관점 (분양·PF)

대주 관점으로 바꾸면 필요한 브릿지·본PF 한도와 분양률 하락 시 상환 가능 여부를 확인할 수 있습니다.

5저장하고 다시 검토하기 · 1분

  • 처음 저장: 숫자를 수정한 뒤 결과 아래 이 조건 저장을 누르고 딜 이름을 입력합니다. 입력값이 v0.1로 저장됩니다.
  • 매입가 변경: 매입가를 바꾸고 이 조건 저장을 다시 누릅니다. 새 버전으로 저장되며, 버전 설명은 비워도 됩니다.
  • 다음 검토: 딜 보관함에서 저장한 딜을 고릅니다. 도구 · AI 모델 깊이에서 “버전(2)·백업”을 열고 “이전과 비교”를 누르면 직전 버전과 달라진 가정·결과를 볼 수 있습니다. 괄호 안 숫자는 저장된 버전 수입니다.

이 브라우저에만 저장됩니다. 다른 PC로 옮길 때는 .modelter로 내보내세요.

6검토 결과 전달하기 · 2분

결과 아래 “결과 공유”에서 “결과 링크 (읽기 전용)”를 고릅니다. 이 링크를 전달하면 되며, 임차인명은 자동으로 가려집니다.

엑셀에서 작업을 이어갈 때

  • 오피스·물류 매입: 6개, 렌트롤 반영 시 7개. 일반 매입은 A&R에서 가정과 보유기간(3~10년)을 바꿉니다. 렌트롤을 반영한 모델의 보유기간은 웹에서 바꾸고 다시 다운로드하세요.
  • 공동주택 분양: 6개. 금액과 비율은 입력 셀에서 바꿉니다. 일정과 민감도는 웹에서 바꾸고 다시 다운로드하세요.
  • 리파이낸싱: 4개. 파일에 들어 있는 대안은 입력 셀에서 수정합니다. 새 대안은 웹에서 추가하고 다시 다운로드하세요.

위 숫자는 작업 시트 수입니다. 엑셀에서 바꾼 값은 웹에 자동 반영되지 않습니다.

자주 묻는 질문

딜 정보가 외부로 나가지 않나요?

기본 계산과 저장은 브라우저 안에서 처리되며 딜 수치는 모델터 서버로 전송되지 않습니다. AI 정밀 추출을 직접 선택한 경우에만 IM 내용이 본인 API 키와 함께 Anthropic으로 전송됩니다.

화면 숫자와 엑셀이 다르면 어떡하죠?

같은 계산식에서 나오도록 만들었고, 실제 수식 엔진으로 엑셀을 재계산해 화면과 일치하는지 상시 검증합니다. '화면 = 다운로드 엑셀' 배지가 그 표시입니다. 차이를 발견하면 제보해 주세요.

팀원이 결과를 보려면 설치가 필요한가요?

아니요. 읽기 전용 공유 링크를 보내면 받는 사람은 브라우저에서 결과와 민감도를 볼 수 있습니다. 값을 바꾸려면 '내 모델로 열기'를 누르면 됩니다.
