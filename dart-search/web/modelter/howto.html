1딜 유형과 예시 확인 · 1분

오피스·물류·분양·리파이 중 해당하는 유형을 고릅니다. 기본 예시로 입력 항목과 결과를 먼저 확인할 수 있습니다.

강남 A타워, 판교 A지구, 분당 B빌딩은 실제 시세가 아닌 샘플입니다. 임대료나 Exit Cap을 바꿔 어떤 값이 결과에 크게 영향을 주는지 확인하세요.

2내 딜 숫자 넣기 · 5~10분

입력 방법은 세 가지입니다. 금액을 넣으면 억·조 단위 환산값도 함께 표시됩니다.

A. 폼에 직접 입력

핵심 입력에는 오류를 확인하기 위한 참고 범위가 표시됩니다. 참고 범위와 기본값은 샘플이며 시점, 입지와 자산에 따라 달라집니다. 실제 딜의 근거를 따로 확인하고, 비어 있는 항목에 적용된 기본값도 검토하세요.

B. 모바일이면 ⚡핵심만 위저드

이동 중이라면 입력 패널의 ⚡ 핵심만 버튼을 누르세요. 핵심 입력을 한 개씩 큰 글씨로 물어보고, 마지막에 KPI 미리보기와 자동 판정까지 보여줍니다.

C. IM 텍스트 자동 인식

오피스·물류의 도구 · AI 모델 깊이 → IM에서 숫자 가져오기를 열고 IM 붙여넣기 → 자동 인식을 선택하세요. 브라우저가 매입가, 연면적, 임대료, Exit Cap 등을 찾아 보여주며, 확인한 항목만 입력값에 반영됩니다. 복잡한 문서는 본인 Anthropic API 키를 쓰는 AI 정밀 추출(β)로 다시 볼 수 있습니다.

기본 자동 인식은 네트워크를 사용하지 않습니다. AI 정밀 추출을 선택하면 IM 텍스트와 API 키가 브라우저에서 api.anthropic.com으로 직접 전송되고 모델터 서버는 거치지 않습니다. 문서 반출과 외부 API 사용에 관한 사내 정책을 먼저 확인하세요.

3결과 읽기 · 3분

숫자를 바꾸는 즉시 결과가 갱신됩니다. 화면 수치는 내려받는 엑셀과 같은 계산식에서 나옵니다(파리티 검증).

4리스크 점검 · 5분

기본안만 보지 말고 가정이 나빠졌을 때 결과가 어디까지 내려가는지도 확인합니다.

민감도 히트맵

5×5 표에서 Exit Cap과 성장률(또는 선순위 금리)에 따른 레버드 IRR 변화를 확인합니다. 분양 사업은 분양률과 분양가에 따른 사업이익률, 손익분기·PF 상환한계 분양률을 봅니다.

렌트롤 업로드 (오피스·물류)

임차인별 계약을 붙여넣으면 현 계약·공실 해소·만기 롤오버를 분해해 연도별 NOI로 전개하고, WALE·만기 집중·최대 임차인 비중 같은 임대차 리스크를 자동 산출합니다. 임차인 실명은 화면·엑셀·공유에서 가릴 수 있습니다.

대주 관점 (분양·PF)

대주 관점으로 바꾸면 필요한 브릿지·본PF 한도와 분양률 하락 시 상환 가능 여부를 확인할 수 있습니다.

5저장하고 다시 검토하기 · 1분

  • 처음 조건 저장: 내 딜 숫자를 수정한 뒤 결과 아래 이 조건 저장을 누르고 딜 이름을 입력합니다. 첫 조건이 v0.1로 저장됩니다.
  • 매입가 변경: 매입가를 바꾼 뒤 이 조건 저장을 다시 누르면 새 버전으로 남습니다. 버전 설명은 비워도 됩니다.
  • 다음 검토: 딜 보관함에서 저장한 딜을 다시 엽니다. 아래 도구 · AI 모델 깊이의 버전(2)·백업 → 이전과 비교에서 직전 버전과 달라진 가정·결과를 확인합니다. 괄호 안 숫자는 저장된 버전 수입니다.

6검토 결과 전달하기 · 2분

결과 아래 결과 공유 → 결과 링크 (읽기 전용)를 선택해 전달합니다. 임차인명은 자동으로 가립니다.

엑셀에서 작업을 이어갈 때

  • 오피스·물류 매입: 6개, 렌트롤 반영 시 7개. 일반 매입은 A&R에서 가정·보유기간(3~10년)을 수정합니다. 렌트롤 기간은 웹에서 수정 후 다시 받습니다.
  • 공동주택 분양: 6개. 금액·비율은 입력 셀에서 수정하고, 일정·민감도는 웹에서 다시 생성합니다.
  • 리파이낸싱: 4개. 생성된 대안의 입력 셀을 수정할 수 있습니다. 새 대안은 웹에서 추가합니다.

작업 시트 수 기준입니다. 엑셀에서 바꾼 값은 웹에 자동 반영되지 않습니다.

자주 묻는 질문

딜 정보가 외부로 나가지 않나요?

기본 계산과 저장은 브라우저 안에서 처리되며 딜 수치는 모델터 서버로 전송되지 않습니다. AI 정밀 추출을 직접 선택한 경우에만 IM 내용이 본인 API 키와 함께 Anthropic으로 전송됩니다.

화면 숫자와 엑셀이 다르면 어떡하죠?

같은 계산식에서 나오도록 만들었고, 실제 수식 엔진으로 엑셀을 재계산해 화면과 일치하는지 상시 검증합니다. '화면 = 다운로드 엑셀' 배지가 그 표시입니다. 차이를 발견하면 제보해 주세요.

팀원이 결과를 보려면 설치가 필요한가요?

아니요. 읽기 전용 공유 링크를 보내면 받는 사람은 브라우저에서 결과와 민감도를 볼 수 있습니다. 값을 바꾸려면 '내 모델로 열기'를 누르면 됩니다.
