엑셀 자가검증 시트, IC PPT 표지, 요약 카드 PNG와 검토 메모에는 위 빌드 식별자가 들어갑니다. 같은 식별자로 산출물과 검증 결과를 연결해 어떤 빌드에서 나온 값인지 확인할 수 있습니다.

직접 재현하는 법

저장소에서 아래 명령을 실행하면 같은 검사를 재현할 수 있습니다. formulas는 엑셀 수식을 파이썬에서 다시 계산하며 모델터 계산 엔진과는 별도로 동작합니다.

  1. pip install formulas — 엑셀 수식 재계산 라이브러리 설치
  2. node tools/parity/gen-xlsx.js office — 예시 딜로 엑셀 생성 + 화면 계산값(기대치) 기록
  3. python3 tools/parity/check.py office — 생성된 엑셀의 수식을 재계산해 화면 계산값과 대조(허용 오차는 지표별 1e-3~1e-2 — 실측 오차는 e-10 이하)
  4. office 자리에 logistics·dev·refi를 넣어 딜별로 반복 — 4딜 전수

허용 오차는 부동소수점 반올림 수준입니다. 계산이나 엑셀 로직을 바꾸면 이 검사를 다시 실행하며, 값이 맞지 않으면 배포하지 않습니다.

파일 안에서도 확인할 수 있습니다

엑셀의 검증 시트에는 생성 당시의 화면 값이 함께 들어갑니다. 수식이나 입력값이 바뀌면 PASS/FAIL 결과로 확인할 수 있고, 빌드 식별자로 이 페이지의 검증 결과도 찾을 수 있습니다.
