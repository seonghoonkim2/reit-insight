모델터는 화면에 보이는 수치와 내려받는 엑셀의 수식이 같은 결과를 낸다고 말합니다. 그 주장을 개발자 말이 아니라 제3자가 재계산해 검증할 수 있는 공개 증거로 둡니다. 아래는 파이썬 formulas 라이브러리로 엑셀 수식을 독립 재계산해 화면 계산값과 대조한 결과와, 누구나 따라 할 수 있는 재현 절차입니다.

직접 재현하는 법

저장소를 받아 아래를 그대로 돌리면 같은 대조를 재현합니다. formulas는 엑셀 수식을 파이썬에서 독립적으로 재계산하는 오픈소스로, 우리 계산 엔진과 무관한 제3의 경로입니다.

  1. pip install formulas — 엑셀 수식 재계산 라이브러리 설치
  2. node tools/parity/gen-xlsx.js office — 예시 딜로 엑셀 생성 + 화면 계산값(기대치) 기록
  3. python3 tools/parity/check.py office — 생성된 엑셀의 수식을 재계산해 화면 계산값과 대조(허용 오차 5e-4 이내면 PASS)
  4. office 자리에 logistics·dev를 넣어 딜별로 반복

허용 오차는 부동소수점 반올림 수준(위 결과의 실제 오차는 그보다 몇 자릿수 작습니다). 계산·엑셀 로직을 고치면 이 대조가 배포 게이트로 다시 돌아, 어긋나면 배포가 막힙니다.

왜 이렇게까지 하나

재무모델은 받은 사람이 셀을 하나 바꾸면 값이 달라집니다. 모델터의 엑셀은 생성 시점 웹 계산값을 검증 시트에 함께 찍어, 받은 사람이 파일 안에서 PASS/FAIL로 변조 여부를 확인할 수 있습니다. 여기에 빌드 식별자와 이 공개 파리티까지 더해, "이 숫자가 어디서 어떻게 나왔는지"를 끝까지 추적할 수 있게 했습니다.
