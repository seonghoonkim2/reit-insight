물류센터 매입 재무모델

물류센터 매입가, 임대료 또는 연 NOI, 대출 조건으로 IRR과 DSCR을 계산합니다. 임대 중인 자산의 매입 검토용입니다. 토지 매입부터 공사·임대 안정화까지 계산하는 개발 모델은 제공하지 않습니다. 작업 시트는 기본 6개, 렌트롤 반영 시 7개입니다.

내 값으로 계산하기 →기본 예시가 들어 있습니다. 첫 입력부터 바꾸면 결과가 다시 계산됩니다.

넣는 값

  • 매입가·연면적(평)
  • 면적 가중평균 임대료 또는 연 NOI
  • 공실률·임대료 상승률
  • LTV·금리·상환
  • Exit Cap·보유기간

나오는 값

  • 레버드/언레버드 IRR
  • Equity Multiple·CoC
  • 최소 DSCR·Debt Yield
  • Cap×성장률 민감도

예시 — 이천 물류센터

넣은 값
연면적35,000 평
매입가 · 감정가2,100억 · 2,150억
평당 임대료 · 관리비33,000원 · 1,700원 /월
공실률 · NOI 성장률5% · 연 2.5%

실제 거래가 아닌 연습용 예시입니다. 운영비와 관리비도 실제 검토하는 자산의 조건으로 바꿔 주세요.

이 조건으로 계산 결과 보기 →위 표의 값으로 열립니다. 내 조건으로 바꾸며 비교할 수 있습니다.

물류 계산 순서

  1. 딜 유형에서 물류센터 매입을 고릅니다
    물류센터 매입 예시가 열립니다
  2. 연면적·평당 임대료를 실제 조건으로 바꿉니다
    층별 임대료가 다르면 면적 가중평균을 넣습니다. 연 NOI만 있으면 “NOI로 입력”을 선택합니다
  3. 공실·임대료 상승률을 계약 조건에 맞춥니다
    책임임대차도 임차인 신용, 계약 만기와 중도해지 조건을 따로 확인합니다
  4. LTV·Exit Cap으로 금융·매각 가정을 맞춥니다
    대출 조건과 매각 시점의 임대차·거래사례를 기준으로 가정합니다
  5. 재무모델 엑셀을 내려받습니다
    화면 수치와 같은 계산식이 들어 있습니다

엑셀에서 이어서 검토하기

엑셀의 A&R 입력 셀에서 가정을 수정할 수 있습니다. 일반 매입 모델의 보유기간은 3~10년 안에서 변경할 수 있으며, 계약별 렌트롤을 적용한 모델의 보유기간은 웹에서 수정한 뒤 다시 내려받습니다.

다운로드 시점의 화면 결과와 엑셀 계산값이 일치하는지 검증합니다. 입력한 딜 데이터는 브라우저 안에서 처리됩니다. 검증 결과 보기 →

자주 묻는 질문

물류센터는 오피스와 무엇이 다른가요?

계산 구조는 같고 운영비·관리비의 예시값이 다릅니다. 상온·저온 여부와 임대인이 부담하는 비용, 계약 조건은 해당 자산에 맞게 확인하세요.

책임임대차(마스터리스)는 어떻게 반영하나요?

별도 마스터리스 선택 항목은 없습니다. 계약상 임대료, 공실과 상승률을 직접 입력하거나 렌트롤을 반영합니다. 책임임대차라는 이유만으로 공실률을 0으로 두거나 임차인 위험이 없다고 가정하지 않습니다.

평당 임대료가 층별로 다르면?

층별 월 임대료 합계를 해당 임대면적으로 나눈 가중평균을 입력합니다. 계약별 만기·렌트프리·상승률을 나누어 검토하려면 렌트롤을 반영합니다.

물류센터 개발도 계산할 수 있나요?

물류 모델은 매입 검토용입니다. 개발·PF 탭은 공동주택 분양 사업수지이며, 물류센터의 공사·임대 안정화·매각을 계산하는 양식은 아닙니다.
